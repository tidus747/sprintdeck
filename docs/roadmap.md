# Roadmap

This describes intended direction, not promises or already available future functionality.

| Version | Scope | State |
| --- | --- | --- |
| 0.1 | Initial local controller, three overlays, JSON persistence, timers, checklists, import/export | Implemented |
| 0.2 | Session notes and Markdown recap, full-month calendars, holidays and time off, shared planning context, large Board Discussion scene; capacity removed | Implemented; manual OBS validation required before release |
| Unreleased | Welcome and Roadmap Review scenes, exact 16:9 capture apertures, colored milestones, and local footer clocks | Implemented; manual OBS validation required |
| Unreleased documentation | Project homepage, searchable guides, six-scene fictional gallery, and GitHub Pages workflow | Implemented; publication tracked separately |
| 0.3 | Reusable meeting types, templates, improved scene configuration and session management, larger-team presentation UX | Planned |
| 0.4 | Optional OBS WebSocket scene control | Planned |
| 1.0 | Stable extensibility model, improved exports, release packaging, and mature documentation | Planned |

External project management integrations are not required. Future integrations must stay optional and preserve a useful local workflow.
